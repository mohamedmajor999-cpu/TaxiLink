Lecture du tableau

L'affichette photographiée correspond aux tarifs 2025 (avant revalorisation). Le code applique les tarifs 2026 issus de l'arrêté national du 24/12/2025, en vigueur depuis le 1ᵉʳ février 2026 — d'où l'écart systématique de +1 à +5 centimes.

Couleurs lumineux

A blanc · B orange · C bleu · D vert. C'est la lettre que doit afficher le compteur du chauffeur selon l'horaire et la zone ZUPC.

À faire côté code

Ajouter les suppléments bagage, encombrant, 5ᵉ personne+ dans marseilleFareEstimate.ts, exposer les champs sur le formulaire de course, et chiffrer le supplément réservation auprès de la préfecture.
