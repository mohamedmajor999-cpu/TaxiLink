🔔 Les notifications du chauffeur

Quand est-ce que le téléphone fait du bruit ?

1️⃣ Nouvelle course près de toi

✅ Le tel BIPE, même app fermée

┌─────────────────────────────────┐ │ 🚖 TaxiLink │ │ │ │ Nouvelle course │ │ Départ : 12 rue de la Paix │ │ │ └─────────────────────────────────┘ ↑ écran de verrouillage

🎯 Quand ? Quelqu'un poste une course dans ton département.

📡 Comment ? Serveur → Expo Push → Google/Apple → ton tel bipe.

2️⃣ Pop-up dans l'app

❌ Pas de bip — popup seulement si app ouverte

┌──────────────────────┐ │ Nouvelle course │ │ │ │ Départ : │ │ 12 rue de la Paix │ │ │ │ [Plus tard] [Voir] │ └──────────────────────┘

🎯 Même évènement que le #1, mais en plus quand l'app est ouverte.

3️⃣ Course RIEN QUE POUR TOI

❌ Pas de bip — carte dans l'app avec compte à rebours

┌────────────────────────────────┐ │ 🎯 Course pour toi ! │ │ │ │ 📍 12 rue de la Paix │ │ 🏁 Gare de Lyon │ │ 💰 35€ │ │ │ │ ⏱️ 18 secondes │ │ │ │ [ Refuser ] [ Accepter ] │ └────────────────────────────────┘

🎯 Quand ? Le serveur t'a choisi TOI (le plus proche).

4️⃣ Quelqu'un a pris ton annonce

❌ Pas de bip — point rouge 🔴 dans l'app

┌────────────────────────────┐ │ ☰ TaxiLink 🔴 │ │ │ │ [Courses] [Annonces 🔴] │ │ │ │ ✅ Marc a pris ta course │ │ Paris → Lyon │ └────────────────────────────┘

🎯 Quand ? Tu postes une course, un pote chauffeur l'accepte.

5️⃣ Ton annonce trouve pas preneur

❌ Pas de bip — point orange 🟠 dans l'app

┌────────────────────────────┐ │ ☰ TaxiLink │ │ │ │ ⚠️ Annonce stuck │ │ Paris → Lyon │ │ Personne l'a prise │ │ depuis 2 minutes │ └────────────────────────────┘

🎯 Quand ? Après 2 minutes sans preneur.
