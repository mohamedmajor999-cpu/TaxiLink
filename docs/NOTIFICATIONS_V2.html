🚨 Le résumé en 1 phrase

Aujourd'hui, seul UN cas fait biper le tel quand l'app est fermée :
une nouvelle course postée dans ton département.

Tous les autres évènements (annonce acceptée, offre exclusive, etc.)
sont silencieux ou cachés dans des points colorés dans l'app.

🔴 Où sont les voyants rouge/orange dans l'app ?

👉 Une seule page concernée : l'écran "Mes courses" (qu'on ouvre depuis le menu hamburger).

⚠️ Pour voir ces voyants, il faut :

  1. Ouvrir l'app
  2. Aller sur l'écran Mes courses
  3. Voir le point rouge sur le hamburger (= "y'a un truc")
  4. Cliquer l'onglet Annonces
  5. Lire la bannière "X nouveautés"

❌ Aucun bip, aucune vibration, aucune notif lockscreen.

🚨 Donc 3 choses à coder

1Push notif "Ton annonce a été acceptée"

Quand un autre chauffeur prend une course que tu as postée
→ Le tel bipe : "Marc a pris ta course Paris → Lyon"

Aujourd'hui : silence total, t'es au courant SEULEMENT en ouvrant l'app.

2Push notif "Offre exclusive pour toi"

Quand le serveur t'attribue une course en exclusivité (20-30 sec pour accepter)
→ Le tel bipe : "Course pour toi ! Ouvre vite l'app pour accepter"

Aujourd'hui : tu ne le sais QUE si l'app est déjà ouverte au bon moment.

3Bannière in-app style WhatsApp

Quand l'app est ouverte mais que tu n'es PAS sur la carte
→ Une bannière descend du haut, tu cliques, ça t'amène sur la course

Aujourd'hui : un gros Alert.alert au milieu qui te bloque, peu importe où tu es.
