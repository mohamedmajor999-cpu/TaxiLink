1. Synthèse exécutive

En une page : TaxiLink doit éviter l'agrément CNDA propre (150-300 k€) et passer par un partenaire API. Le meilleur candidat est Orisha Intellio Éditeurs (ex-Sephira), qui propose un moteur SESAM-Vitale via API REST en marque blanche, avec hébergement HDS inclus. Côté pricing chauffeur, le marché est verrouillé à 25-35 €/mois illimité. La stratégie recommandée : 3 plans (Essentiel 19 €, Pro 29,90 €, Premium 49 €) + tarif flotte dégressif + add-ons à fort margin (avance trésorerie 1,5 %, lecteur en location 9 €).

2.2 Top 3 recommandations classées

1Orisha Intellio Éditeurs — le meilleur fit fonctionnel

Moteur SESAM-Vitale via API REST + HDS inclus + ils connaissent déjà le métier taxi (Intellio Taxi en parallèle). Tarif historique Sephira ~25,90 €/mois — modulé sur devis pour les éditeurs.

2Olaqin Stellair API — plan B sécurisé

Leader historique des lecteurs bi-fente, programme "Éditeur/Revendeur" annoncé. Limite : taxi conventionné pas dans la cible affichée — il faudra demander d'étendre.

3GIE SESAM-Vitale SEFi — voie noble en Phase 3+

Service officiel de l'Assurance Maladie pour taxi conventionné, mais encore en expérimentation depuis avril 2020. Pas pour le MVP — à mettre en veille active.

2.3 Pourquoi écarter Cegedim ?

Cegedim/Resocom ne publie aucun tarif et ses contrats partenaires sont opaques. Coût de mise en route estimé : 25 k€ setup + licences chauffeur élevées. Surtout, leur modèle est plutôt licence revente que API moderne. Pas adapté à un MVP serré.

3.2 Forces et faiblesses détaillées

Orisha — Forces

  • Couvre 100 % du flux (FSE + DRE + tous téléservices)
  • HDS clé en main, BAL gérée → rien à provisionner côté TaxiLink
  • Vrai modèle B2B2C, doc avec exemples de code
  • Sephira : 26 000 pros équipés, 30 ans d'expérience
  • Pas besoin que TaxiLink soit agréé CNDA

Orisha — Faiblesses

  • Concurrent direct via Intellio Taxi — clause de territoire ou non-cannibalisation à exiger
  • Tarif sur devis, négociation B2B
  • Possiblement contrat exclusif (à éviter)
  • Délai de signature commercial (2-3 semaines mini)

Olaqin — Forces

  • Marque rassurante (ex-Ingenico Healthcare)
  • Bundle possible : lecteur bi-fente + API
  • Programme Éditeur/Revendeur explicite
  • Plateforme web Stellair moderne

Olaqin — Faiblesses

  • Taxi conventionné non listé — extension à négocier
  • Cible historique : médecins, sages-femmes, IDE
  • Doc API moins détaillée publiquement
  • Possiblement plus cher au volume
